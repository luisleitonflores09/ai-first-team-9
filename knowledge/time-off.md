# Northstar Labs time off

Northstar Labs is a fictional company used for a training demo.

## Requesting leave

An employee requests planned time off in the fictional Leave Portal. The employee's manager reviews the request. The employee should wait for approval before treating the leave as confirmed.

## Changes to a request

To change a pending request, the employee cancels it in the Leave Portal and submits a new request. For a request that has already been approved, the employee contacts their manager.
